The Focused Philosophy

Built for Clean Uninstalls, Not System Tweaking

Windows debloaters modify telemetry, disable services, and tweak registry policies. HailUninstaller does one thing with absolute precision.

1. Native Uninstaller First

Never bypasses the developer's official uninstall sequence. HailUninstaller triggers the official uninstaller first to let it unhook cleanly, then searches for what was left behind.

2. Multi-Subsystem Deep Scan

Scans across AppData (Local/Roaming/LocalLow), ProgramData, Program Files, Registry (HKCU/HKLM/WOW6432Node), orphaned Services, and Scheduled Tasks.

3. Zero Naive Wildcards

Never deletes with blind wildcards like *Name*. Candidates are scored using multi-factor evidence while protected Windows paths are strictly immune.

Automation Ready

Comprehensive CLI Parameters

Integrate HailUninstaller into provisioning scripts, system administration pipelines, or unattended deployments.

.\HailUninstaller.ps1 -List List all registered 32/64-bit and MSIX applications.
.\HailUninstaller.ps1 -Scan "Discord" Perform read-only leftover analysis without touching files.
.\HailUninstaller.ps1 -DeepScan "Blender" Exhaustive multi-subsystem scan with evidence scoring.
.\HailUninstaller.ps1 -Uninstall "App" -DeepClean -CreateBackup Complete automated uninstall, backup snapshot, and deep cleanup.
.\HailUninstaller.ps1 -Restore "2026-10-02_Discord" Revert deleted files and re-import registry snapshots from manifest.
